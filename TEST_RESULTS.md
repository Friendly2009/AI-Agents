## Ограничения проверки

- Вызов настоящей ИИ-модели не выполнялся: ключ и модель заказчика не предоставлены. Путь запроса, разбора и сохранения ответа проверен с `httpx.MockTransport`.
- Настоящие RSS-ленты пока не выбраны; XML обработчик проверен на RSS/Atom fixtures. Для приёмки нужно согласовать доступный источник с достаточной историей.
- Playwright-проверка интерфейса была подготовлена, но **не выполнена**: установленный Playwright не имел Chromium, попытка загрузки вернула некорректный архив. Поэтому визуальный вид и клики в браузере не подтверждены. Сценарий оставлен в `qa/browser-check.cjs`; синтаксис страницы и API проверены отдельно.
- Windows и systemd deployment не запускались в этом окружении. Python-код переносим, инструкции и unit-файл предоставлены для настройки на целевой машине.
- Не проводилась недельная эксплуатация, проверка доходности стратегии или нагрузочное тестирование.
- Pytest показал одно предупреждение внешней библиотеки Starlette: её TestClient считает использование httpx устаревающим. Это не падение теста; версии сохранены для воспроизводимости.

## Как повторить

Из корня проекта после установки зависимостей:

```bash
python -m pytest -q
ruff check --config pyproject.toml .
python -m market_agent analyze
```

Для дополнительного браузерного теста нужен Node.js и доступный Playwright Chromium: установите `playwright` в отдельное окружение (`npm install --no-save playwright`, `npx playwright install chromium`). Запустите демо-сервер на порту 8765 с `SCHEDULE_ENABLED=false`, затем `node qa/browser-check.cjs`. Скрипт использует ключ из локального `.env`, проверяет вход, запуск, историю, мобильную ширину, выход и создаёт локальные изображения в `qa/`. Эти изображения не включены в архив.
