# Anastasiya AI в Docker Desktop

Выполняйте команды из `D:\vscodeprojects\AI-Agents\Anastasiya-AI` в PowerShell. Docker Desktop должен работать в режиме Linux containers.

## Первый запуск и перенос

1. Остановите Windows-слушатель и панель через Ctrl+C. При переносе с Docker остановите исходный стек командой `docker compose down`.
2. Скопируйте всю остановленную папку `data`, включая файлы SQLite, WAL, журналы и `sessions`, в отдельный закрытый каталог. При переносе скопируйте также проект, `.env` и `config`. Не запускайте исходную и перенесённую копии одновременно.
3. Соберите образ и проверьте сессию. Тестовый режим в этой команде действует только на первый запуск. При необходимости введите код Telegram и пароль 2FA в своём терминале. Дождитесь сообщения об активации слушателя, затем нажмите Ctrl+C.

```powershell
docker compose build
docker compose run --rm -e SAFE_TEST_MODE=true listener
```

4. Запустите постоянные сервисы. Режим слушателя определяется локальным `.env`.

```powershell
docker compose up -d
docker compose ps
docker compose logs --tail=100 listener panel panel-gateway
```

## Панель

Откройте http://127.0.0.1:8765 в браузере. Получите код через /панель или выполните в своём терминале команду ниже. Она берёт ADMIN_OWNER_TG_ID из окружения контейнера и печатает одноразовый код.

```powershell
docker compose exec panel sh -c 'python scripts/launch.py admin_panel --login-code "$ADMIN_OWNER_TG_ID"'
```

Введите код на странице в течение пяти минут. Приложение проверяет Host, Origin, cookie и CSRF-токен. После перезапуска панели откройте страницу заново и запросите новый код.

## Обслуживание

- Штатная остановка — `docker compose down`. Рабочая папка `./data` сохраняется на Windows.
- После изменения `.env` — `docker compose up -d --force-recreate`.
- После изменения кода — `docker compose up -d --build`.
- Для восстановления остановите стек, переименуйте текущую папку `data` в отдельную резервную копию, скопируйте сохранённый каталог целиком под именем `data` и запустите стек. Восстановление старого ledger откатывает историю доставки. Перед включением рабочего режима сверьте операции, выполненные после копии.
- Контейнеры читают список разрешённых групп через `./config:/app/config:ro`. SQLite, сессии, каталоги и состояние фоновых задач находятся в `./data:/app/data`. Дополнительная утилита `render_panel_demo` записывает демонстрационные материалы в `evidence` и в обычном запуске не участвует.
- Версии установленных Linux-зависимостей зафиксированы в `requirements-docker.lock`, образы Python и nginx закреплены по digest. В контекст сборки входят перечисленные в `.dockerignore` исходники и ресурсы. Локальный `.env` передаётся через Compose.
