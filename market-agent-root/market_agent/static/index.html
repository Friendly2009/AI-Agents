MARKET AGENT / WEEKLY RESEARCH

План по акциям MOEX

Бюджет, новости и обоснованные сценарии покупки, продажи или ожидания

Подключение

Введите API_TOKEN из .env. Ключ хранится только в памяти вкладки.

Ваши условия

Сохранённый профиль используется для ручного и еженедельного анализа. Данные обновляйте после реальных сделок. До заполнения профиля расписание создаёт только обзоры.

Без этой отметки покупки — модельный сценарий, продажи не рассчитываются. Позиции вводятся в штуках, не в лотах. Если есть бумаги вне списка, сначала расширьте markets.live.json.

Пожелания помогают модели объяснить выбор; обязательные числовые ограничения задаются полями выше. Для анализа профиль и позиции передаются настроенной модели. Сделки программа не совершает.

Подключения

Проверка делает один короткий запрос к ИИ. План по профилю отправляет подходящие акции одним запросом; при HTTP 503 возможны ещё две попытки.

История

Выберите отчёт или запустите новый анализ.
Расчётные показатели и выводы ИИ отмечаются отдельно. Демо-режим использует синтетические данные.
