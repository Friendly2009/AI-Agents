# Анастасия 4.14 — консультация, которая помогает решиться

## Что изменилось
Единый сценарий вместо накопленных дополнений: текущий запрос → интерес/задача ребёнка → подходящий подтверждённый результат → ответ на сомнение → предложение понятного шага → оформление при готовности.

Подсказка модели на каждом ходе учитывает сомнение, жалобу на давление, паузу и недавнее приглашение. Отдельная программная проверка блокирует переход к оформлению для распознанных сомнений и пауз, даже если модель вернула неправильное действие. Распознавание эвристическое: это дополнительная защита, а не гарантия понимания любой формулировки.

Сохранены отдельная чистая память теста, отключение реальных действий в тесте, уведомления двум руководителям и подключение AlfaCRM. В новой версии обязательный файл sales_context.py.

## Установка
Остановить старое окно Ctrl+C. Сделать резервную копию рабочей папки. Заменить все .py из архива и start.cmd. Не заменять свои .env, data и knowledge.json. Запустить start.cmd. Отправить /диалог_тест. Повтор команды начинает новый тест, /конец_теста завершает его.

## Проверка общения
Каждый сценарий начинайте с /диалог_тест. Реплики ниже — примеры для ручной проверки, а не результаты живого тестирования модели.

| Написать | Что ожидаем |
|---|---|
| Привет 👋 | Короткое приветствие без старой записи |
| Ребёнку 10, любит игры. Мы в Александрове. Что есть и сколько стоит? | Ответ на цену и подходящий вариант; без повторного возраста и города |
| Она рисует, программировать не хочет | Творческая рекомендация; без навязывания программирования |
| Сыну 15. Он сам решает, куда ходить | Уважение выбора подростка, без обещания гарантированного интереса |
| Не знаю, понравится ли | Один полезный довод или вопрос об интересе, если он неизвестен; без оформления |
| Дорого | Известная стоимость/состав и спокойный ответ, без выдуманной скидки |
| Мы уже ходим в другую школу | Без критики конкурентов; выяснить, что ищут дополнительно |
| Вы давите. На какое занятие вообще? | Признание поспешности и объяснение, без очередного «записать?» |
| Подумаю | Короткая пауза, без телефона и нового приглашения |
| А ребёнку 30 лет? | Уместная реакция на контекст/шутку, не менять возраст ребёнка автоматически |
| Да, расскажите (после предложения рассказать) | Рассказать, не считать согласием на запись |
| Да, придём (после конкретного приглашения) | Только недостающие сведения, без повторной презентации |
| В воскресенье не можем | Не предлагать снова ту же дату и не придумывать свободное время |
| Где вы находитесь? | Подтверждённый адрес из базы; если его нет — честно уточнить |
| Подготовка к ОГЭ по информатике в Ярославле | Ответ по экзамену/филиалу, без перевода на мастер-класс в Александрове |

## Как оценивать
На каждой реплике: ответила на вопрос; помнит данные; показала конкретную пользу, когда уместно; не повторяет приглашение; не выдумывает условия; не переходит к оформлению при сомнении. Отдельно отмечайте длинные и неестественные ответы.

Локальные проверки проверяют код и ограничения действий. Они не доказывают качество ответов GPT или рост конверсии. Живой прогон с моделью и реальная CRM в этой сборке не проверялись. Сравнивайте долю заинтересованных, заявок и фактических посещений на сопоставимых обращениях; не только число приглашений.

## Что ещё влияет на результат
Для убедительного ответа нужна точная база: адрес каждого филиала, возрастные условия конкретного занятия, действительно доступные даты, стоимость и реальные примеры работ. Фото/отзывы/результаты нельзя выдумывать. Событие 8 ноября 2026 прекращает предлагаться после начала; следующую дату нужно утвердить отдельно.
